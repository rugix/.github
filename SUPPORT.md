# Support

Rugix is an open-source project developed by
[Silitics](https://silitics.com). The
[Rugix Support Commitment](https://rugix.org/support-commitment/) explains
what support to expect from core components, maintained integrations,
examples, and experimental projects. Individual repositories declare their
support tier in their README when applicable.

## Public Support

For usage questions and design discussions, use
[GitHub Discussions](https://github.com/orgs/rugix/discussions). For
reproducible bugs and feature requests, use the issue tracker of the relevant
repository.

Please include the Rugix version, relevant configuration, logs or error
messages, and a small reproducible example where possible. Public support is
provided on a best-effort basis without guaranteed response times.

## Security Issues

Do not report security vulnerabilities publicly. Follow the
[Rugix security policy](https://github.com/rugix/rugix/security/policy) to
report them privately.

## Commercial Support

For defined response times, production support, long-term maintenance,
architecture reviews, or custom engineering, see
[Rugix Commercial Support](https://rugix.org/commercial-support/).
